# 信医健康 · 全周期健康管理服务生态（H5）

公司展示 H5 网页静态站点，移动端优先，支持 GitHub Pages 在线访问。

## 项目目标
为客户提供公司品牌展示、诊疗服务、中医文化与六大康养基地宣传的移动端 H5 页面。

## 在线访问
- GitHub Pages：https://kongbai20233.github.io/xinyi-health-h5/

## 目录结构
- index.html 主页面（含企微客服区）
- assets/ 图片与企微二维码素材

## 使用说明
- 在线：直接访问上方 GitHub Pages 链接。
- 离线：保持 index.html 与 assets/ 同级，双击打开 index.html 即可，勿单独发送 HTML 文件。

## 部署说明
推送 main 分支后，GitHub Pages 自动发布站点（构建源：main 分支 / 根目录）。
